## Changes

- Windows: the first release. `Plaitway-0.6.0-x64-en-US.msi` and `Plaitway-0.6.0-x64-zh-TW.msi` install the helper as the service `PlaitwayHelper`, the command line client `plaitway` and a native app (WinUI 3, self-contained, no .NET or Windows App Runtime needed). WireGuard profiles run on wintun; OpenVPN profiles run on the OpenVPN installation of the PC, which is not part of the package. Routes are written through the IP Helper API and DNS settings as NRPT rules. A profile file dropped on the window is imported
- The Windows packages are not signed yet, so SmartScreen warns at the first run; the checksums are in `SHA256SUMS-windows`. Removing the package keeps `%ProgramData%\Plaitway`, because the profiles hold private keys
- A replaced tunnel route is deleted only after the route that replaces it is in the verified table, so a failed add no longer leaves the traffic of a full tunnel on the physical default route. A route that another VPN overrides raises a warning on the profile, and the IPv6 next hop of an OpenVPN tunnel is the far end of the tunnel address

The macOS app and the Linux packages are the same as in 0.5.0, apart from the route change above, which applies to every system.
