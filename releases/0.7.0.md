## Changes

- Windows: a new app, written in Rust and drawn with Direct3D 11, in place of the WinUI one. The window is the routing graph: each profile, the routes it asks for and which tunnel holds each of them, with Mica on Windows 11 and a plain background on Windows 10. Profiles can be imported (or dropped on the window), edited, renamed, reordered by dragging and deleted; Logs and Diagnostics show the daemon's own journal; the helper service can be installed, updated and removed from the app. It follows the language of Windows (English or 繁體中文, **Settings › Language** chooses), keeps running in the tray, and exposes its controls to screen readers through UI Automation. The program is 2.3 MB and needs no runtime
- Windows: OpenVPN is part of the package. `openvpn.exe`, `tapctl.exe` and the TAP-Windows6 driver of OpenVPN 2.7.1, as the OpenVPN project signs them, are installed in the `openvpn` folder and used first; an OpenVPN you installed yourself is still the fallback. The notices carry the GPLv2 source offer for them
- Windows: a zip, `Plaitway-0.7.0-x64.zip`, for anyone who wants no installer: the same files and a `README.txt` that says where to put them and how to register the helper
- Windows: fixed an OpenVPN profile failing with `Adapter ... is using ovpn-dco driver, tap-windows6 expected` on a PC that has the ovpn-dco driver too (any OpenVPN 2.7 installation): the daemon now asks for a TAP-Windows6 adapter by its hardware id
- Windows: upgrading from 0.6.x with the MSI replaces the app in place; the profiles and settings are kept

The macOS app and the Linux packages are the same as in 0.6.1. Windows 10 has not been tried.
