## Changes

- A WireGuard profile whose AllowedIPs gives an address a `/0` prefix, such as the `192.168.50.0/0` that ASUS routers write for their LAN, now gets a warning: WireGuard reads it as `0.0.0.0/0`, so the profile is a full tunnel. The warning is on the import report, on the Configuration page after a save, and in the Overview of a connected profile, which is where a profile imported before this release shows it
- The Homebrew cask no longer makes Homebrew warn that its macOS requirement is written in a deprecated way

The app, its window and the menu bar are the same as in 0.3.0.
