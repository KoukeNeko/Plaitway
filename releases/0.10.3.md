## Changes

- Linux: the menu of the GNOME Shell extension shows the state of each profile beside its switch: a spinner while the profile connects, reconnects or disconnects, a check mark when it is connected, a cross when it has failed, a key when it awaits credentials, and a dim dot when it is not connected
- Linux: while the extension is loaded in the running Shell, the app no longer shows its own tray item, so that only one icon represents Plaitway in the top bar. The tray item is shown again when the extension is disabled, and stays where the Shell cannot be queried. Closing the window then quits the app, as it does without a tray; the helper keeps the profiles connected, and the extension's menu opens the window again

The macOS app, the Windows app and the helper are the same as in 0.10.2.
