## Changes

- Linux: the global menu (File, View and Help in the top bar) now works under Wayland. The menu bar is exported with `Gtk.Application.set_menubar`, which GTK publishes on the session bus and tells the desktop about for the window, where the X11 window id that 0.8.0 relied on does not exist. Under X11 the menus still reach a global menu through the registrar

The macOS app, the Windows app and the helper are the same as in 0.10.0.
