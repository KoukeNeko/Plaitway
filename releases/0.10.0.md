## Changes

- Linux: a GNOME Shell extension, `plaitway@koukeneko.github.io`, for the top bar: an icon and the number of connected profiles, and a menu with a switch for each profile, **Disconnect All** and **Open Plaitway**. It works with the window closed, in English or 繁體中文 as the session is. The package installs it; **Tools** in the sidebar installs it for one user, enables or disables it, and says what it does. The Shell reads its extensions when it starts, so log out and back in after the first time
- Linux: **Tools** is a new page at the bottom of the sidebar, in categories; GNOME Shell extensions are the first
- Linux: **Settings › Show Menu Bar** shows File, View and Help under the header bar of the page. It is off by default, and does not depend on a global menu

The macOS app, the Windows app and the helper are the same as in 0.9.0.
