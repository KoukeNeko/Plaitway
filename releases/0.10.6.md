## Changes

- Command line: `plaitway disconnect -all` disconnects every profile that is on, as **Disconnect All** does in the app
- Command line: `plaitway move profile place` changes a profile's priority, as dragging it in the sidebar does. The place is `top`, `bottom`, `up`, `down` or a position counted from 1
- Command line: `plaitway remove-route key` deletes a stale route that `plaitway diagnostics` lists, as **Remove** on the diagnostics page does
- Command line, Linux: when a profile requests credentials, `plaitway connect` first uses the credentials the app saved in the Secret Service (GNOME Keyring, KWallet), and asks for them only when none are saved, they cannot be read or the server refuses them. The command line only reads the keyring; it does not unlock a locked keyring, and asks for the password instead. With `-username` it does not use the saved credentials
- Linux: `packaging/linux/uninstall.sh` removes Plaitway completely: the app, the GNOME Shell extension, the credentials saved in the keyring, the app's files in the home directory, the package with every stored profile and its private keys, and the apt repository. It lists what it removes and asks for confirmation first; `--dry-run` only lists it. See [Uninstall](https://github.com/KoukeNeko/Plaitway/blob/main/Docs/uninstall.md)

The apps and the helper are the same as in 0.10.5.
