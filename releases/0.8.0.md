## Changes

- Linux: the app has the Routing page of the Windows app, and it opens on it. Routes are on the left, tunnels on the right, and a line joins each route to every tunnel that asks for it: solid where the tunnel holds the route, dotted with a cross where it waits behind a tunnel of higher priority. Pointing at a route or a tunnel dims the other lines, a route can be selected to read who holds it and who waits behind it, and each tunnel has its own Connect or Disconnect button. In a narrow window the page is a list of routes with a chip for each tunnel ("Home holds", "Office waits")
- Linux: the sidebar lists Routing above the profiles. Each profile has a dot in its own colour (filled while it is on, a ring while it is off), the same colour as its lines on the Routing page, and says `WireGuard · Holds 2 of 3 routes` while it is connected
- Linux: **Settings › Blur Sidebar** makes the sidebar translucent, so that a compositor that blurs what is behind a window (KDE, GNOME with Blur my Shell) shows it blurred. It is off by default; without such a compositor the sidebar is only translucent
- Linux: the window's menus (File, View and Help) are exported to a global menu, for a desktop that shows the menu bar of the focused application outside its window (KDE, Unity, GNOME with a global menu extension). Under Wayland the window has no id for the desktop to know it by, so start the app with `GDK_BACKEND=x11` to get it there

The macOS app, the Windows app and the helper are the same as in 0.7.0.
