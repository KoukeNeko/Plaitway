## Changes

- macOS: the bar of Logs and Configuration stays at the top of the page when there is nothing below it, such as a log with no lines; it was centred in the window with a gap above it
- macOS and Linux: the Received and Sent columns of a profile's Overview share the width, so a longer number in one no longer moves the other
- Linux: the traffic uses arrows and Diagnostics a magnifier, in the sidebar and the page
- Linux: a signed apt repository at https://koukeneko.github.io/Plaitway/ installs Plaitway and brings the later versions with `sudo apt upgrade`, as the install steps below say

The helper is the same as in 0.4.1.
