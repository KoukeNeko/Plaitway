## Changes

- Linux: a profile that requires credentials can be connected from the GNOME Shell extension's menu. The extension no longer waits for the connection to complete; the app answers the credential request with the password saved in the keyring, or opens its window and asks for it. Previously the profile was stopped as soon as it requested credentials, and its switch returned to off
- Linux: when the app starts before the Shell has loaded the extension, as it can at login, its tray item is now hidden once the extension loads. Previously both the tray item and the extension's icon remained in the top bar
- Linux: while the extension is loaded, closing the window hides it and the app keeps running in the background, so that it can answer credential requests; the extension's menu opens the window again

The macOS app, the Windows app and the helper are the same as in 0.10.3.
