## Changes

- Linux without systemd, such as Gentoo with OpenRC: the helper runs as an OpenRC service under `supervise-daemon` that restarts it after a crash without limit, and `packaging/linux/install.sh --openrc` installs the service with a logrotate file for its log. The app says "Start plaitwayd, for example with rc-service plaitwayd start." where it cannot start the helper itself, and `plaitway` names `rc-service plaitwayd status` instead of `systemctl`
- Linux without systemd-resolved: the DNS servers of a full tunnel go through openresolv, as the only servers in `resolv.conf` while the tunnel is up. A profile whose DNS is for some domains only cannot be set this way, and its Routes and DNS page says so. The helper warns at start when NetworkManager writes `resolv.conf` itself, which replaces the tunnel's servers; `rc-manager=resolvconf` in NetworkManager's configuration stops that
- Gentoo: a live ebuild of this repository, `packaging/linux/gentoo`, builds and installs the helper, the command line client and the app with the system's Go. Gentoo's Go has no `LICENSE` in `GOROOT`, which stopped the build of the third-party notices; they now take the Go license from a Go module
- openresolv 3.16, the version of Gentoo, words its message for a name without an entry differently from 3.13, which made every full tunnel fail to set its DNS; both are read now

The macOS app and its helper are the same as in 0.4.2. On Debian and Ubuntu the helper behaves as before; only the hint of the command line client depends on the init system now.
